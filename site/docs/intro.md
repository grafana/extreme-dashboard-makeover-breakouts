# Welcome

Welcome to the **Extreme Dashboard Makeover Breakouts**. In one hands-on breakout (with an optional take-home challenge), you'll transform a dull dashboard into a polished, production-quality one, learning both the manual dashboarding fundamentals and where **Grafana Assistant** can speed things up.

## How this workshop works

This breakout teaches dashboarding two ways at once.

The **manual walkthroughs** are the main path. Each panel makeover walks you through the clicks: visualization types, value mappings, thresholds, transformations, overrides, layout. These are the fundamentals every Grafana user benefits from knowing.

The **Assistant prompts** appear where they earn their keep: repetitive sub-tasks, bulk operations across panels, and quick variant exploration. By the end of the breakout, you'll have seen both how a dashboard is built by hand and where AI accelerates the parts you wouldn't want to repeat.

### Take-Home Challenge (optional)

An open-ended creative challenge you can tackle on your own time. You'll build a **KitchenOps** dashboard from library panels, applying anything you learned in the breakout: manual technique, Assistant, or both.

## What you'll need

- A modern web browser
- A URL to a Grafana Cloud instance (provided by your facilitator)
- A personal login (provided by your facilitator)
- Grafana Assistant enabled on the instance

If you didn't receive a username and password, please speak to your friendly facilitator!
