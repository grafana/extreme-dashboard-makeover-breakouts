# Dashboard Makeover

We will be revamping the following dashboard.

![Dull Dashboard](/img/breakout1/dull-dashboard.png)

Our existing dashboard already has useful information: RED metrics (request rates, errors, and duration/latency) for our service, state information for the underlying Kubernetes pods, and end-user activity from a geographic lens. Our aim is to make that information easier to understand and more visually appealing.

## Prerequisite: import the starter dashboard

1. Click the menu button (☰) at the top left, and then click on *Dashboards*.
2. On the Dashboards screen, click the *New* button and then click *Import*.
3. On the Import Dashboard screen, in the *Import via grafana.com* field, type in `16413` and then click *Load*.
4. You will be asked to choose three of your dashboard's data sources:
    - For TestData DB, choose `TestData DB`.
    - For Prometheus (Cloud), choose `Prometheus (Cloud)`.
    - For LokiNGINX, choose `Loki (Cloud)`.
    - Click on *Import*.

## Get oriented with Grafana Assistant

We'll do most of this workshop by hand, but Grafana Assistant shows up at key moments. Get it open before you start so it's ready when you need it.

1. Look for the **Assistant icon** in the top navigation bar; it looks like a sparkle/star icon. Click it to open the Assistant sidebar.

    ![Assistant Icon](/img/breakout2/assistant-icon-top-nav.png)

2. At the bottom of the Assistant sidebar, click the model or mode selector and switch to the **dashboarding version** of Assistant. This version is specifically tuned for dashboard creation and editing tasks.

    ![Assistant Mode Selector](/img/breakout2/assistant-mode-selector-dashboarding.png)

3. You should now see a chat interface on the right side of your screen, with your dashboard visible on the left.

    ![Assistant Sidebar Open](/img/breakout2/assistant-sidebar-open.png)

When a step shows an Assistant prompt, you'll see a code block like this:

```assistant title="Suggested prompt"
This is what an Assistant prompt looks like in this workshop.
```

Copy the prompt into the Assistant sidebar (or rephrase in your own words) and let it work.
