## How This Workshop Works

This workshop is structured as a series of hands-on breakouts that build on each other. Here's the path you'll follow:

### Step 1: Breakout 1 — Solo Makeover (Do this first)

Start here. In this breakout, you'll manually transform a dull dashboard into a polished, production-quality one. You'll learn how Grafana panels, thresholds, value mappings, and visualizations work under the hood — step by step, click by click.

This foundation matters. Understanding how dashboards are built manually makes you a more effective user of the AI-assisted tools in Breakout 2.

**When you're done** (or when the presenter signals to move on), proceed to Breakout 2.

If you didn't finish every step in Breakout 1, don't worry — there's an import option at the bottom of that page to load the completed dashboard so you can start Breakout 2 from a known-good state.

### Step 2: Breakout 2 — AI-Assisted Dashboard Refinement (Do this second)

This breakout picks up where Breakout 1 left off. You'll use Grafana Assistant to refine the dashboard you just built — applying bulk edits, improving accessibility, adding drilldowns, and discovering monitoring gaps, all through natural language conversation.

You'll need the finished dashboard from Breakout 1 as your starting point. If you didn't complete it, import the pre-built version (dashboard ID `16414`) as described at the start of Breakout 2.

### Step 3 (Optional): Take-Home — Individual Challenge

This is an open-ended creative challenge you can tackle after the workshop on your own time. You'll build a KitchenOps dashboard from library panels, applying the manual techniques from Breakout 1 and the AI-assisted workflows from Breakout 2 — your choice of approach.
